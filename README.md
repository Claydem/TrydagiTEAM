
# MindPace — Десктопний органайзер часу та фокусу з підтримкою когнітивної стабільності

> Настільний застосунок на платформі .NET / C# для структурованого тайм-менеджменту, усвідомленого планування та подолання компульсивних перевірок і тривожності.

---

## 1. Опис проєкту та призначення

**MindPace** — це спеціалізований десктопний інструмент персонального планування, розроблений для користувачів, які стикаються з прокрастинацією перфекціонізму, компульсивними паттернами перепровірки завдань (прояви ОКР/тривожних розладів) та когнітивним перевантаженням від хаотичних to-do списків.

Мета застосунку — не просто вести перелік справ, а створити безпечне, контрольоване та передбачуване цифрове середовище. MindPace допомагає доводити задачі до завершення, зменшувати кількість сумнівів щодо виконання («чи дійсно я все закрив/зробив?») та керувати робочими інтервалами за допомогою адаптивних методик тайм-менеджменту.

---

## 2. Проблема та цільові користувачі

### Проблема
1. **Компульсивні перевірки та сумніви (ОКР-паттерни):** Люди з ОКР або підвищеною тривожністю витрачають багато енергії на багаторазове відкриття списків, перевірку правильності виконаних кроків або сумніви у завершеності дії.
2. **Параліч планування (Decision Paralysis):** Класичні планувальники заохочують створювати безрозмірні списки на 50+ пунктів, що викликає фрустрацію, тривогу та небажання починати роботу.
3. **Тиск дедлайнів і прострочених справ:** Агресивні червоні індикатори та покарання за пропущені дні лише поглиблюють відчуття провини.

### Цільові користувачі
* Люди з проявами ОКР, підвищеним рівнем тривожності та схильністю до румінацій (нав'язливих думок).
* Студенти, інженери та фахівці розумової праці, які мають проблеми з утриманням фокусу та відчувають перевантаження від надмірної кількості дрібних завдань.

## 4. Основний функціонал

### Модуль когнітивного тайм-менеджменту
* **Суворі WIP-ліміти (Work In Progress):** обмеження на кількість активних задач на день (не більше 3–5 пріоритетних), що блокує безконтрольне розростання списку.
* **Тайм-боксинг та інтервальний фокус:** адаптивний таймер (варіації Pomodoro 25/5 або 50/10) із чіткою прив'язкою поточної сесії до обраної задачі.
* **Безпечні перерви:** обов'язкове блокування робочого екрана під час відпочинку для запобігання вигоранню.

### Модуль подолання компульсивних дій (OCD-friendly)
* **Протокол усвідомленого завершення («Closure Protocol»):** замість звичайного кліку на чекбокс, задача закривається через фіксацію результату (коротка перевірка: «Дію виконано — Зафіксовано — Відпущено»).
* **Заморожування завершених задач:** після остаточного закриття задача переміщується в «Архів виконаного» і блокується від повторного редагування на кілька годин, зменшуючи тригер до постійного перепровіряння.
* **Журнал підтверджень:** можливість відкрити деталі задачі та переглянути точний час і мітку підтвердження («Підтверджено о 14:32:10»), що заспокоює тривогу щодо забутих дій.

### Аналітика без тиску
* Відображення фактично інвестованого часу замість відсотка невиконаного.
* Відсутність покарань чи скидання прогресу за пропущений день.

## 5. Технологічний стек

* **Мова програмування:** C# (.NET 8.0+)
* **Тип застосунку:** Desktop Application (WPF / XAML або Windows Forms)
* **Робота з даними:** ADO.NET (прямі параметризовані SQL-запити, контроль транзакцій)
* **База даних:** PostgreSQL / Microsoft SQL Server
* **Тестування:** xUnit / NUnit (модульні тести для Core Logic)
* **Журналювання:** Serilog (запис у локальні структуровані файли логів)
* **CI/CD:** GitHub Actions (автоматична компіляція рішення та запуск тестів при створенні Pull Request)
* **Управління проєктом:** GitHub Projects (Kanban-дошка)

## 6. Архітектура застосунку

Застосунок будується за багаторівневою архітектурою (Layered Architecture):

```text
├── MindPace.UI          // Представлення: форми, XAML-компоненти, валідація введення (Мирко)
├── MindPace.Core        // Бізнес-логіка: таймери, правила закриття, аналітика (Олександр)
├── MindPace.Data        // Доступ до даних: репозиторії ADO.NET, з'єднання з БД, транзакції (Тарас)
├── MindPace.Common      // Спільні моделі, DTO, конфігурація логування
└── MindPace.Tests       // Автоматизовані модульні тести (Олександр)

# Зацікавлені сторони проекту

1. Студенти та школярі — користувачі, яким потрібно планувати виконання навчальних робіт (лабораторних, курсових) та контролювати дедлайни.
2. Користувачі на дистанційному навчанні або роботі — люди, яким потрібен простий інструмент для планування робочого часу та концентрації уваги без відволікань.

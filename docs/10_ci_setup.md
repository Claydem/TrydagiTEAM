# Налаштування неперервної інтеграції (CI)

1. Призначення пайплайну:
- автоматична перевірка збирання проекту при кожному push або Pull Request у гілку main;
- автоматичний запуск модульних та інтеграційних тестів проекту MindPace.Tests;
- додаткові перевірки якості коду та вразливостей залежностей.

2. Конфігурація GitHub Actions (.github/workflows/ci.yml):
- середовище виконання: windows-latest (потрібне для збирання WPF-застосунку під .NET 10);
- кроки пайплайну: відновлення залежностей (dotnet restore), збирання у конфігурації Release, запуск тестів (dotnet test) та перевірка якості.

3. Перевірка результатів:
- статус виконання кожного запуску відображається у вкладці Actions репозиторію GitHub;
- злиття змін у main виконується після успішного проходження перевірок.

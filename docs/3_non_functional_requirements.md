# Нефункціональні вимоги

1. Простота використання: графічний інтерфейс побудований на базі трьох вкладок, навігація інтуїтивна та не потребує додаткового навчання.
2. Швидкодія: час запуску програми не перевищує 2 секунд, робота таймера та оновлення інтерфейсу відбуваються без затримок і зависань.
3. Автономність: програма працює локально на ОС Windows без необхідності підключення до мережі інтернет або встановлення сторонніх СКБД.
4. Надійність: валідація вхідних даних (заборона створення проектів із порожніми назвами, від'ємним часом або дедлайнами у минулому).

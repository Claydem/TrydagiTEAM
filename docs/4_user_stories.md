# Історії користувача (User Stories)

Історія 1
Як користувач, я хочу додавати свої проекти з дедлайнами та оцінкою потрібного часу, щоб бачити повний перелік завдань в одному місці.

Критерії приймання:

[ ] У інтерфейсі є доступна кнопка/форма для створення нового проекту.

[ ] Форма створення проекту містить поля: Назва (текст, обов'язкове), Опис (текст, необов'язкове), Орієнтовна кількість годин (числове значення, обов'язкове) та Дата дедлайну (вибір дати, обов'язкове).

[ ] Після збереження новий проект з'являється у загальному списку проектів із початковим статусом «Активний».

[ ] Користувач може переглядати повний список створених проектів разом із їхніми поточними статусами.

[ ] Користувач має можливість позначити проект як виконаний або видалити його зі списку.

[ ] Користувач може вручну додати відпрацьований час до проекту (крок у +30 хвилин).

Історія 2
Як користувач, я хочу бачити щоденну норму годин для кожного проекту, щоб рівномірно розподілити навантаження і встигнути все вчасно.

Критерії приймання:

[ ] Система автоматично розраховує кількість годин на день, необхідних для завершення проекту до встановленого дедлайну (на основі залишок годин і днів).

[ ] Інтерфейс відображає розраховану щоденну норму для кожного окремого проекту.

[ ] На головному екрані відображається підрахунок загального рекомендованого часу роботи на поточний день по всіх активних проектах.

[ ] Реалізовано графік навантаження на найближчі 7 днів, який візуально показує розподіл завдань у часі.

[ ] Розрахунки та графік оновлюються автоматично при зміні прогресу проекту чи дедлайну.

Історія 3
Як користувач, я хочу запускати таймер на вказаний мною час, щоб зосередитися на виконанні поточної задачі і не відволікатися на сторонні речі.

Критерії приймання:

[ ] Користувач може встановити або обрати час для роботи у таймері.

[ ] Інтерфейс таймера містить функціональні кнопки: Запуск (Start), Пауза (Pause) та Скидання (Reset).

[ ] Зворотний відлік часу відображається на екрані в реальному часі.

[ ] Програмою відтворюється звуковий сигнал у момент завершення робочого інтервалу або перерви.

[ ] Під час активної роботи таймера інтерфейс блокує відвідування інших вкладок/розділів програми, щоб забезпечити концентрацію.

Історія 4
Як користувач, я хочу, щоб відпрацьований у таймері час автоматично додавався до проекту, щоб не вести облік вручну.

Критерії приймання:

[ ] Після успішного завершення сесії таймера для вибраного проекту відпрацьований час автоматично зараховується на користь цього проекту.

[ ] Прогрес проекту в загальному списку оновлюється одразу після закінчення таймера.

[ ] Усі зміни (статус проектів, накопичений час) автоматично та безперервно зберігаються у локальний JSON-файл.

[ ] Під час наступного старту програми всі збережені дані (проекти, час, прогрес) коректно завантажуються з локального JSON-файлу та відображаються в інтерфейсі.

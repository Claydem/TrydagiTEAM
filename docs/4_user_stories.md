# Історії користувача (User Stories)

1. Як користувач, я хочу додавати свої проекти з дедлайнами та оцінкою потрібного часу, щоб бачити повний перелік завдань в одному місці.
2. Як користувач, я хочу бачити щоденну норму годин для кожного проекту, щоб рівномірно розподілити навантаження і встигнути все вчасно.
3. Як користувач, я хочу запускати таймер на вказаний мною час, щоб зосередитися на виконанні поточної задачі і не відволікатися на сторонні речі.
4. Як користувач, я хочу, щоб відпрацьований у таймері час автоматично додавався до проекту, щоб не вести облік вручну.

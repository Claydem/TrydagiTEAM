# Функціональні вимоги

1. Управління проектами:
- створення проекту із зазначенням назви, опису, орієнтовної кількості годин та дати дедлайну;
- перегляд списку створених проектів та їх статусів;
- можливість додавання відпрацьованого часу вручну (+30 хвилин);
- позначення проекту як виконаного або видалення зі списку.

2. Тайм-менеджмент та планування:
- автоматичний розрахунок кількості годин на день, необхідних для завершення проекту до дедлайну;
- підрахунок загального рекомендованого часу роботи на поточний день;
- відображення графіка навантаження на найближчі 7 днів.

3. Концентрація уваги (таймер):
- зворотний відлік часу;
- кнопки запуску, паузи та скидання таймера;
- звуковий сигнал при завершенні робочого інтервалу або перерви;
- блокування відвідування інших вкладок під час таймеру роботи.

4. Збереження даних:
- автоматичне збереження списку проектів та прогресу у локальний JSON-файл;
- завантаження збережених даних при старті програми.
